# Support

Use the [GitHub issue tracker](https://github.com/klaevv/vscode-copilot-status-bar/issues)
to report a bug or request a feature.

Before filing an issue:

1. Run **Copilot Status Bar: Refresh**.
2. Open **Copilot Status Bar: Show Log** and copy the non-sensitive error text.
3. Include your VS Code version, extension version, operating system, and the
   steps needed to reproduce the problem.

Do not include GitHub access tokens, cookies, email addresses, or other account
credentials in an issue.

## Known service dependency

This extension relies on undocumented GitHub Copilot endpoints. A GitHub-side
API change or outage can make quota information temporarily unavailable even
when the extension itself has not changed.
